# 情报服务平台离线演示版

## 运行方式

1. 先完整解压压缩包，不要直接在压缩包预览窗口中运行。
2. 双击 `index.html`，或双击 `启动情报服务平台.cmd`。
3. 建议使用最新版 Chrome 或 Edge，分辨率 1920×1080、浏览器缩放 100%。

本版本为纯 HTML、CSS、JavaScript 离线演示页面，无需安装依赖、启动服务或连接网络。

## 演示入口

默认从“新建情报分析任务”进入，完整业务路径为：

Anduril 企业级分析 → Lattice 平台级分析 → Lattice Mesh 技术还原。

左侧导航可进入：

- 产品技术谱系构建
- 技术发展态势研判
- 技术辅助还原与破解

业务分析结果中的“查看执行详情”可进入三项关键技术页面。

## 录屏时间

- 三层业务分析：自动运行约 26 秒，并为两次跨层人工点击预留约 4 秒，总体控制在约 30 秒。
- 动态信息采集：约 20 秒。
- 多源跨模态情报对齐融合与动态演化关联分析：约 20 秒。
- 多维信息价值评估：约 20 秒。

## 注意事项

- 请保持文件夹结构不变，不要单独移动 HTML 文件。
- 页面使用样例研判数据和公开资料研判内容，仅供分析参考。
- 页面运行不联网、不随机；刷新页面后可重新开始流程。
