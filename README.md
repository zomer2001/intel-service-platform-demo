# 情报服务平台 · 八场景离线版

## 八场景现场动线合并版（2026-09-22）

**推荐入口：双击根目录的 `打开情报服务平台.html`。** 先完整解压整个文件夹，不要仅发送一个 HTML 文件，也不要在压缩包内直接打开。`打开两场景.html` 仍可直接进入目录；`index.html` 保留公共组件示例，不是业务首页。

本版本以综合工作台和八场景动线为主框架，合入增强后的动态监测、技术路线、差距分析和真实开源项目索引。目录包含 27 个对象、35 条来源和 54 条证据；路线图包含 20 个节点；开源矩阵包含 11 个固定真实项目，并可通过离线智能体回放增加 Zenoh 候选。本轮不代表重新核验全部历史事实。

推荐主线：目录选择 **Lattice** → 查看时间图谱 → 返回技术产品目录 → 查看前沿技术动态监测 → 关键技术路线演化 → 选择路线节点 → 技术成熟度分析报告 → 对比当前方案（弱网与断连）→ 相关开源项目 → 对应仿真验证参数包。支持返回继续研究；Tab、对象、路线、差距和项目通过查询参数传递。

补充路径：Dive-LD → 关联 Lattice；或 Ghost-X → Ghost 系列时间图谱。任务中心仍可进入原 Anduril → Lattice → Lattice Mesh 三级流程。

每条来源摘要随包保存在本地；点击“打开原始来源”才需要互联网。未核实的历史日期、厂商标称参数、未来计划及采用关系在详情中明确区分；不以补齐页面为由编造参数。未找到可靠配图的对象使用文字标识，不用其他产品图片冒充。

**数据边界：当前方案（样例基线，非实际测评）。** 双方对标分数均为样例，不是实际能力差距，也不等同于 TRL。开源项目仅是候选研究参照，不代表 Lattice 实际采用。“仿真验证参数包”按所选开源项目生成，包含仓库概览、代码入口、架构、可提取能力、可信度和建议验证步骤；不代表 Lattice 内部参数，也不表示已经运行真实仿真。

本轮没有联网采集、后台服务、自动测试框架或新增依赖。保留原品牌、监测详情和开源/参数布局，保留三级任务及三项关键技术页。只有原始来源及官方仓库外链需要联网。

## 打开方式

直接双击 `打开情报服务平台.html`，或在 Mac 的 Chrome / Safari 中打开该文件。页面使用相对路径，设计为通过 `file://` 运行，无需安装依赖、启动服务或联网。

## 文件说明

- `index.html`：公共框架与组件示例。
- `page-template.html`：后续页面复制模板。
- `assets/brand/`：品牌 Logo。
- `css/variables.css`：视觉变量。
- `css/layout.css`：导航、顶栏和主区域布局。
- `css/components.css`：Card、Button、Table、Tab、Loading、Empty 和 Drawer 样式。
- `js/data.js`：少量示例数据。
- `js/layout.js`：平台外壳和正式导航。
- `js/components.js`：公共组件与 Drawer 基础能力。
- `js/evidence.js`：Evidence Drawer。
- `js/workflow.js`：Workflow Drawer。

## 复制新页面

复制 `page-template.html` 并保持 CSS、JavaScript 的加载顺序。新页面位于子目录时，需要相应调整资源相对路径。

## 技术产品目录成果页

打开 `pages/applications/lineage.html?tab=catalog` 可查看技术产品目录。页面使用统一表格在一页内呈现全部对象，并按应用场景归组、使用不同颜色标签区分；支持关键词、对象类型和应用场景筛选。点击对象名称可打开详情抽屉，可用 `?tab=catalog&object=dive-ld` 直接打开 Dive-LD 完整对象档案。该页面继续使用本地相对资源，可通过 `file://` 直接运行。

## 技术发展态势研判

打开 `pages/applications/trends.html`，可通过四个单行 Tab 查看前沿技术动态监测、技术领域总体趋势、关键技术路线演化和关键技术差距分析。支持对象、事件、证据、报告、路线节点和差距维度详情，报告可在浏览器本地生成并下载。

## 技术辅助还原与破解

打开 `pages/applications/restoration.html`，可通过四个单行 Tab 查看业务场景推演方案集、技术原理拆解图谱、开源项目索引矩阵和仿真验证参数包。开源矩阵使用公开仓库记录；选择项目后，可查看项目概览、真实文件入口、代码架构、技术映射和项目级验证参数包，并可导出本地 JSON。智能体过程为固定、可审计的离线回放，不联网、不随机。

两个新增业务应用均使用 JavaScript 数据文件直接加载，不依赖 `fetch`，可继续通过 `file://` 直接运行。Tab 状态记录在 `?tab=` 查询参数中。
